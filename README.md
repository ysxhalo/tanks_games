# 🎮 坦克大战 - Tank Battle

使用 **Next.js 14** + **TypeScript** + **Canvas API** 构建的经典坦克大战游戏。

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 游戏操作

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → 或 WASD | 移动坦克 |
| 空格键 | 射击 |
| Enter | 重新开始 |

## 游戏特性

- 🎯 玩家控制蓝色坦克，使用 WASD/方向键移动，空格射击
- 🤖 敌人 AI 具备追踪玩家和自主射击能力
- 🧱 砖墙可被摧毁，钢墙不可摧毁，水域阻挡坦克
- ⭐ 保护基地（金色旗帜）不被摧毁
- 📈 得分系统 + 生命值 + 波次生成敌人
- 🎨 精美 Canvas 渲染（渐变、纹理、发光效果）

## 技术栈

- **Next.js 14** (App Router)
- **TypeScript**
- **Canvas API**
- **TailwindCSS**
