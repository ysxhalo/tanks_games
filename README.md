# 🎮 坦克大战 - Tank Battle

使用 **Next.js 14** + **TypeScript** + **Canvas API** 构建的经典坦克大战游戏。

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

打开 http://localhost:3000 即可游玩。

## 游戏操作

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → 或 WASD | 移动坦克 |
| 空格键 | 射击 |
| P / Escape | 暂停 / 继续 |
| M | 开关音效 |
| Enter | 确认 / 重新开始 |

## 🎯 游戏目标

- 消灭所有敌人，保护基地（金色旗帜）不被摧毁
- 共 **4 个关卡**，逐关递增难度
- 每关通关后自动进入下一关

## ✨ 游戏特性

### 🔊 音效系统
- 使用 Web Audio API 合成音效，无需外部音频文件
- 射击、爆炸、拾取道具、过关、胜利、失败均有音效
- 按 **M 键** 随时开关

### ⭐ 道具系统
击败敌人有 25% 概率掉落道具，拾取获得增益效果：

| 道具 | 效果 | 持续时间 |
|------|------|---------|
| ⚡ 加速 | 移动速度 ×1.8 | 5 秒 |
| 🛡️ 无敌 | 免疫所有伤害 | 5 秒 |
| 💥 散弹 | 一次发射 3 发子弹 | 5 秒 |
| ❤️ 加命 | 立即增加一条生命 | 即时 |

### 📊 关卡系统
| 关卡 | 敌人数量 | 特点 |
|------|---------|------|
| 第 1 关 | 6 | 入门级，标准地图 |
| 第 2 关 | 8 | 堡垒地图，更多钢墙 |
| 第 3 关 | 10 | 水域迷宫，需要迂回 |
| 第 4 关 | 12 | 最终要塞，全部敌人类型 |

### 🧠 AI 敌人
四种敌人类型，头顶有标识符号：

| 类型 | 标识 | 行为特点 |
|------|------|---------|
| 🔵 普通型 | — | 随机移动，30%概率追踪 |
| 🔴 激进型 | ★ | 80%追踪，高射速，侧翼包抄 |
| 🟠 防御型 | ● | 守卫基地，攻击靠近的玩家 |
| 🟣 狙击型 | ◆ | 远距离瞄准，寻找直线射击角度 |

### 🏆 排行榜
- localStorage 持久化存储前 10 名高分
- 游戏结束后自动检测是否为高分
- 支持输入名字（最多 8 个字符）
- 前三名显示 🥇🥈🥉 奖牌

### 🎨 视觉与交互
- 精美 Canvas 渲染（渐变发光子弹、砖墙纹理、钢墙铆钉、水域波浪动画）
- 道具浮动旋转动画
- 无敌光晕、加速拖尾特效
- 敌人类型彩色标识
- 关卡过渡动画 + 进度条
- 暂停遮罩界面

### 🧱 地图元素

| 元素 | 说明 |
|------|------|
| 🧱 砖墙 | 可被子弹摧毁 |

## 🐛 Bug 修复记录

### 坦克卡墙问题
- **原因**：基地保护砖墙挡住了玩家出生点，坦克一出生就卡在墙中；移动采用整体检测，一旦卡住无法脱身
- **修复**：保护砖墙自动跳过玩家出生位置；改为轴分离移动（X/Y 轴独立检测），实现沿墙滑动；增加卡死恢复机制，自动将坦克推出墙体

### 子弹无法穿过水域
- **原因**：水域和砖墙/钢墙共用同一套碰撞逻辑，子弹被水域阻挡
- **修复**：子弹碰撞检测中跳过水域类型
